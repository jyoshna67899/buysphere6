# BuySphere — GitHub Pages Ready

Static portfolio project using only HTML, CSS and JavaScript.

## Features
- Product search
- Multi-store price comparison
- Lowest-price detection
- Savings calculation
- Ratings and specifications
- Category and sorting filters
- Wishlist using LocalStorage
- Dark mode
- Responsive design
- No backend, database, API key or server

## GitHub Pages
Upload `index.html`, `style.css`, `app.js` and `README.md` to the repository root. Then go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Data note
The catalog is local demo data. It does not claim to fetch live marketplace prices. Live retailer data requires an authorized API/feed/provider.

## Resume
Developed BuySphere, a responsive client-side product comparison platform using HTML, CSS and JavaScript with multi-store price analysis, savings detection, search, filters, wishlist persistence and dark mode; deployed with GitHub Pages.
